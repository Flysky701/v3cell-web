# V3Cell 首页三幕视频脚本

首页按滚动位置分为三幕。第一幕由滚动驱动，第二、三幕各自从 0 秒计时。两支成片都是 1280 × 720 的二维动画，讲解文字随画面呈现。

## 第一幕 · V3Cell

标题出现，淡色类器官切面位于文字后方。首次向下滚动时，切面缩小并平移到第二幕画幅内，对齐片头淡红色上皮环。落位后用约 1.8 秒叠化到真实片头。第二幕在画面进入视野、叠化完成后开始播放。

## 第二幕 · 静态表征（10 秒）

| 片内时间 | 镜头 |
| --- | --- |
| 0.00 秒 | 淡红色类器官切面接住第一幕的移动。 |
| 1.16 秒 | 取景框标出二维截面，建立观察位置。 |
| 3.00 秒 | 明场显微镜与样本图像出现，连接切面示意和显微观测。 |
| 5.45 秒 | 引入 R3GAN 的模型推断。 |
| 6.00 秒 | 对照灰度图像与虚拟表型。 |
| 7.70–10.00 秒 | 回看同表型的真实与虚拟样本，收束到形态保真度。 |

片旁用淡红标识真实、淡蓝标识虚拟。胃类器官空腔亚型的两幅显微样本分别取自独立样本。

## 第三幕 · 动态命运（18 秒）

本幕切换到独立的羊膜囊类器官研究。桌面左侧讲解，右侧播放动画。窄屏沿阅读顺序上下排列。

| 片内时间 | 镜头 |
| --- | --- |
| 0.00 秒 | 化学扰动与早期观测。 |
| 3.70 秒 | 编码早期序列，进入命运判别。 |
| 6.90 秒 | 展开三种候选形态。 |
| 10.00 秒 | 按预测概率排列候选命运。 |
| 12.20 秒 | 突出预测概率最高的候选。 |
| 14.40 秒 | 沿潜空间推演后续轨迹。 |
| 17.00–18.00 秒 | 显出预测的后续形态，结束。 |

## 预览与微调

从[首页顶部](http://127.0.0.1:3000/?motion=preview#home)下滚可以看完整衔接。本机预览回到页首可以重看。使用 `?motion=once` 检查首访模式。偏好减少动态效果的读者可以手动播放。

第二、三幕保留微吸附。向下滚动停止时，距幕首在视口高度 10% 以内会平滑对齐，耗时约 0.32–0.64 秒。向上回滚保持自由。桌面每幕保留三枚平面漂移切片，窄屏为两枚。

视频离开当前幕时暂停。片下的时间轴用圆点标出上述镜头起点，当前节点随播放高亮。点击圆点可跳转，键盘聚焦节点后也可用左右方向键选择相邻镜头。暂停时选择节点可停在相应画面，全屏可查看细小的图内标注。

切换页面语言时，两部短片随之切换中英文画面和封面，并沿用当前播放时间。英文版保留原片的显微样本、示意图、镜头时长和排序动画，图内标题、标注和讲解使用英文。
