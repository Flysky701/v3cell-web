# V3Cell 论文交互展示 v1.0

网站读者可以沿首页了解研究问题，从结果页追溯论文数值，在工作台检查某一命运、时点、扰动条件或模型模块。三个入口共用中英切换和本机静态服务。参考站为 [scPLAD](https://scplad.net/)。

## 页面和数据流

| 入口 | 读者操作 | 呈现依据 |
| --- | --- | --- |
| `#home` | 每幕自带观察窗，滚动接近时图文一起对齐。首幕可旋转、剖切、标注或放大概念模型。第二幕沿三个谱系进入图谱。第三幕可滚动或点选扰动前、扰动后、状态演变，并可进入论文轨迹对照 | 结构与扰动过程为概念示意。静态缩略图来自图 2，工作台轨迹来自独立羊膜囊研究的图 5A |
| `#research` | 查看 4 张指标卡、两个独立研究阶段、论文题名、作者和图 1 | 图 1，第 5 页；§2.3–2.4；§4.1 |
| `#results` | 使用固定章节导航通读四节或聚焦一节；切换谱系、指标和实验预算；打开数值表、整图及对应正文页 | 图 2–5；第 5–11 页原页可在本地阅读 |
| `#workbench` | 选择命运、播放 7 个时点、在同一时点比较三命运。图 5C 和 5G 上的游标随帧移动，报告的 r 保持整段轨迹的含义 | 虚拟帧来自图 5A。曲线裁自原稿，游标仅映射横轴时间 |
| `#workbench?tab=attribution` | 切换 EHDPP、IDDPP、RGD 并放大四通道；对照区域 nEF 原图和视频样本构成 | 图 5B、5F，第 10–11 页；§4.7–4.8，第 20–22 页 |
| `#workbench?tab=architecture` | 选择 R3GAN、分类器、编码器、MotionRNN、解码器或训练目标；按亚型浏览图 2 的真实和虚拟样本 | §4.3–4.6，第 16–19 页；图 2、图 6 |

结果章节支持 `#results?tab=atlas|quality|phenotyping|temporal`，谱系链接支持 `#results?lineage=colon|stomach|lung`。工作台保留 `#workbench?compare` 并排入口以及 JSON 导出。本地文件使用浏览器对象 URL 预览，导出记录写明论文图号、培养时间和 `live_inference:false`。

## 实现与阅读边界

`dist/data.js` 收录报告值，`evidence.js` 和 `lab.js` 负责图谱、图表和工作台。样本标识由 `assets/samples.json` 维护。提取脚本保存五张整图、23 个子图和 7 张正文原页，并复用论文嵌入图像导出 ROI 与时间帧。首页结构示意与论文图像独立。截图、刻度和统计原值均可离线查阅。

“Virtual 3D Cell”建模三维类器官在二维明场图像平面中的空间形态及其时序演变。首页首幕从玫瑰花结剖面开始，保留实心球、出芽、玫瑰花结与塌陷四种可检查形态。第二幕的连线用于导航到三个静态谱系。第三幕以腔隙变窄为例展示概念过渡，论文轨迹由独立入口回放。四种形态共享对象表面的细胞纹理、冰青色组织切面与深蓝内腔材质。打开标注后，引线随旋转定位到可见结构。全站使用冷调浅色背景，首页的冰白与雾蓝自然延续到研究证据区。背景有轻缓的光晕和弧线，开启系统的减少动态效果后保持静止。本站的科学结果均来自用户提供的论文稿。

三幕使用浏览器原生滚动吸附。桌面将图文并排居中，手机竖屏将图放在对应文字下方。第三幕能完整放入视口时，图文停驻，后续两个吸附位置依次推进形态。文字放大或视口过矮时，整幕可自由滚读，三个阶段也能点选。模型外观静置时约两分钟转一圈，剖面在可见角度内往返。拖动或按方向键后停留三秒再继续，可通过「自动旋转」暂停。系统启用减弱动态效果时，模型保持静置，形态直接切换。
