# 私有协作约定

协作仓库：[Flysky701/v3cell-web](https://github.com/Flysky701/v3cell-web)，当前可见性为 Private。未经明确要求不改为 Public。

- `main` 保持可预览；小修改使用 `feat/...`、`fix/...`、`docs/...` 短期分支。
- 每个 PR 只处理一个具体问题，说明页面变化、科学内容依据和验证方式。
- PR 附桌面与移动端截图；不要把未接入推理的控件描述为已完成预测功能。
- 修改论文数据、类别或指标时，同时更新来源与实验条件。
- 不提交 API 密钥、账号凭据、私有原始数据、权重或用户上传图片。
- 协作者用户名尚未提供，因此本版不自动发出邀请。后续由仓库所有者添加具体成员。
- 当前 CI 不发布网站。部署与仓库可见性是两件独立的事，不能因私有仓库而假定部署也私有。

建议第一批任务：内容复核、移动端视觉反馈、高清素材整理、模型最小接口接入。需求模板位于 `.github/ISSUE_TEMPLATE/feature.yml`。
